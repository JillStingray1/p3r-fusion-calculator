# Persona 3 Reload fusion calculator

This is fusion calculator for game Persona 3 Reload made using Actix Web and Askama.

Persona has a fusion mechanic with its collectable monsters, called persona, fusing 2 personas together will yield a new
persona based on the average of the ingredients base level, as well as the arcanae of the ingredients. This tool is intended to assist
players to recipes that they need.
